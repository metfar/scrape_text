# scrape_text
Bash to scrape text from urls

```
# ./scrape_basic.sh --help

./scrape_basic.sh -h|--help |
		Displays this help

./scrape_basic.sh [urls.txt] [scraped_text]
		Scrapes texts from urls to scraped text directory

# ./scrape_basic.sh 

=== https://example.com -> scraped_text/site_0.txt ===
Example Domain
This domain is for use in documentation examples without needing permission. Avoid use in operations.

=== https://www.iana.org/domains/reserved -> scraped_text/site_1.txt ===
IANA-managed Reserved Domains

```
